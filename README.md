# Diwali Sales Data Analysis Using Python
# Project Overview

This project focuses on analysing Diwali sales data using Python to discover customer purchasing patterns, identify popular product categories, and generate meaningful business insights.

The project demonstrates how Data Science techniques and Exploratory Data Analysis (EDA) can transform raw retail data into actionable information that supports business decision-making.

# Objectives

- Analyse customer purchasing behaviour.
- Identify sales trends across different age groups and genders.
- Explore state-wise and occupation-wise purchasing patterns.
- Identify popular product categories.
- Perform data cleaning and preprocessing.
- Generate meaningful insights through data visualisation.

# Dataset

The dataset contains approximately 11,251 records and 15 original columns, including:
- User_ID
- Gender
- Age Group
- Age
- Marital_Status
- State
- Zone
- Occupation
- Product_Category
- Orders
- Amount

# Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

# Project Workflow

1. Import Python libraries.
2. Load the Diwali sales dataset.
3. Understand and inspect the dataset.
4. Handle missing values and duplicate records.
5. Perform data cleaning and preprocessing.
6. Conduct Exploratory Data Analysis (EDA).
7. Analyse customer demographics and purchasing patterns.
8. Visualise sales trends using charts and graphs.
9. Generate data-driven findings and business recommendations.
